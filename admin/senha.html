Gerar senha da área administrativa

Esqueceu a senha, ou quer trocar sem entrar no painel? Crie uma nova aqui — não precisa da antiga.

Esta página só gera o arquivo config/admin-config.js com o hash da nova senha. Nada é enviado a lugar nenhum: o cálculo acontece no seu navegador. Para valer no site, substitua o arquivo no projeto e faça o commit/push no GitHub (quem pode alterar o repositório já controla o sistema, então esta página não abre brecha nenhuma).
Voltar ao painel
  1. Substitua o arquivo config/admin-config.js do projeto por este conteúdo.
  2. Faça commit + push no GitHub.
  3. Aguarde ~1 minuto e entre no painel com a nova senha.
